# بريف تصميم تطبيق «مشاريع السلطان»

تطبيق جوال (iOS + Android) لنظام CRM عقاري سعودي. نفس بيانات المنصة الحالية، بواجهة مبنية للجوال من الصفر.

---

## ١. المستخدمون والمبدأ

| الدور | الاستخدام |
|---|---|
| **موظف مبيعات** | المستخدم الأساسي — يشتغل من جواله طول اليوم بين المكالمات والزيارات |
| **مالك / مدير** | يتابع الفريق والتوزيع، ما يتصل بالعملاء بنفسه |

**المبدأ الحاكم:** التطبيق ليس نسخة من الويب. نطاقه أضيق عمدًا — التواصل والمتابعة فقط. التقارير والاستيراد والإعدادات والتحليلات تبقى في الويب.

**الاختبار على كل شاشة:** هل الموظف يقدر ينجزها بإبهام واحد وهو واقف؟

## ٣. قواعد عامة (تنطبق على كل شاشة)

- **RTL كامل** — كل شي من اليمين لليسار
- **اللغة:** عربي بلهجة سعودية. لا فصحى ولا مصرية
- **الأرقام:** عربية (١٢٣) في كل مكان
- **المبالغ:** بالريال السعودي كاملة وغير مختصرة — `٥٠٬٠٠٠ ريال سعودي` لا `50K`
- **رقم فال REGA `1200021029`** يظهر في شاشة الدخول وفي «المزيد»
- **مساحة اللمس:** كل عنصر قابل للضغط ٤٤ نقطة على الأقل
- **safe area:** احترام النتش أعلى والشريط السفلي في آيفون
- **الكلمات الإنجليزية** داخل جملة عربية توضع في سطر مستقل (تفادي مشاكل RTL)
- **مصطلحات محظورة على الموظف:** «تلقائي» / «سحب» / «إهمال» / «توزيع» — تظهر للمالك فقط

## ٥. شاشة تسجيل الدخول

خلفية أوبسيديان كاملة، بدون صور.

- شعار Sultan Residence (رمز الباب الذهبي) في الثلث العلوي
- «مشاريع السلطان» تحته بخط متوسط أبيض
- حقلان: البريد / رقم الجوال، ثم الرمز السري
- زر «دخول» ذهبي بعرض كامل، ارتفاع ٥٢ نقطة
- تحته: «نسيت الرمز؟» بخط صغير ذهبي
- **بعد أول دخول ناجح:** عرض تفعيل البصمة / Face ID — «تبي تدخل بالبصمة المرة الجاية؟»
- أسفل الشاشة: `رقم فال ١٢٠٠٠٢١٠٢٩` بخط ١١ لون `#48484C`

**حالات الخطأ:** رسالة حمراء تحت الحقل مباشرة، بلهجة واضحة — «البيانات غير صحيحة، جرّب مرة ثانية».

بعد الدخول: التوجيه حسب الدور — موظف → رئيسية الموظف · مالك/مدير → رئيسية المدير.

## ٦. الرئيسية — الموظف

### أ. الترويسة
```
صباح الخير، عبير
عندك ٧ مهام اليوم
```
يمين الترويسة: دائرة الحرف الأول + نقطة حمراء إن وُجدت إشعارات.

### ب. العدّادات — ثلاث بطاقات في صف

كل بطاقة قابلة للضغط وتفتح القائمة المفلترة مباشرة:

| البطاقة | المعنى | اللون |
|---|---|---|
| **لم يتم التواصل** | عملاء جدد لم يُسجَّل لهم أول تواصل | أحمر |
| **لم يرد** | مرحلة `ATTEMPTED` — حاول ولم يرد | تنبيه |
| **متابعات اليوم** | مستحقة اليوم أو متأخرة | ذهبي |

داخل البطاقة: الرقم كبير (٢٢px) فوق، التسمية صغيرة (١١px) تحت.

### ج. شريط العدّ التنازلي (يظهر شرطيًا)

إذا فيه عملاء ما تم التواصل معهم وقاربت مهلتهم، يظهر شريط تحت العدّادات:

```
٣ عملاء يحتاجون تواصل اليوم   ← اضغط
```
حلقة SVG متحركة ذهبية تتحول لأحمر نابض عند قرب انتهاء المهلة.
**بدون أي ذكر لكلمة «سحب» أو «تلقائي».**

### د. «ابدأ بهذول» — قائمة الأولوية

أقصى ٥ بطاقات، مرتبة: المتأخر ← زيارة اليوم ← جديد لم يُتواصل معه.

**بطاقة العميل:**
```
┌─ شريط لوني بعرض ٣px على اليمين (لون المرحلة)
│  الاسم                                    [بادج الحالة]
│  آخر تواصل قبل ٣ أيام · تيك توك
│  ─────────────────────────────────────
│  [ اتصال ]  [ واتساب ]
└─
```
- زر «اتصال» ذهبي مملوء إذا كان هذا الإجراء الموصى به، وإلا رمادي
- ارتفاع الأزرار ٣٦ نقطة

### هـ. أسفل القائمة
زر نصي خافت: «شوف كل العملاء ›»

## ٧. الرئيسية — المالك / المدير

نفس اللغة البصرية، محتوى مختلف كليًا. لا أزرار اتصال ولا واتساب.

### أ. الترويسة
```
مرحبًا سلطان
نظرة على الفريق اليوم
```
فلتر فترة أفقي: **اليوم · أمس · ٧ أيام · الشهر**

### ب. بطاقات المؤشرات — شبكة ٢×٣

| البطاقة | ملاحظة |
|---|---|
| **غير موزّعين** | إن كان > ٠: بطاقة حمراء + زر «وزّعهم الآن» |
| **إجمالي العملاء** | — |
| **لم يتم التواصل** | عبر الفريق كامل |
| **متابعات اليوم** | مستحقة على الفريق |
| **زيارات اليوم** | — |
| **حجوزات الشهر** | المبلغ المحصّل بالذهبي |

### ج. أداء الفريق

صف لكل موظف:
```
عبير الحربي        ١٢٤ عميل · ٨ متابعات اليوم · ٤ حجوزات
▓▓▓▓▓▓▓░░░  ٧٠٪
```
شريط تقدّم ذهبي. الضغط يفتح صفحة الموظف.

**تمييز بصري:** الموظف اللي عنده متابعات متأخرة يظهر شريطه أحمر.

### د. تنبيهات تحتاج انتباه

قائمة قصيرة، تظهر فقط عند وجود حالات:
- عملاء مكرّرون بانتظار المراجعة
- خصومات تجاوزت الحد
- موظف عليه متابعات متأخرة

### هـ. مصطلحات المالك فقط
هنا فقط تظهر: «التوزيع التلقائي»، «العملاء المسحوبون»، «صامتو التواصل».

## ٨. تبويب «جدد»

عملاء لم يُسجَّل لهم أول تواصل (`firstContactStage === null`).

- الترويسة: «عملاء جدد» + العدد
- ترتيب: الأقدم أولًا (الأطول انتظارًا فوق)
- كل بطاقة تعرض **وقت الانتظار** بوضوح: «وصل قبل ساعتين» / «ينتظر ٣ أيام»
- بطاقة تجاوزت ٢٤ ساعة: شريطها أحمر
- زرا اتصال وواتساب داخل البطاقة
- **حالة فارغة:** أيقونة + «ما فيه عملاء جدد الحين 👌»

---

## ٩. تبويب «متابعات»

مهام اليوم مرتبة بالوقت.

- شرائح فلترة أفقية: **الكل · متأخر · زيارات · اتصالات**
- تجميع بعناوين: «متأخر» (أحمر) ثم «اليوم» ثم «بكرة»
- بطاقة المهمة:
```
زيارة — نورة القحطاني              ١١:٠٠
مشروع ٨٠ · شقة ١٢
[ اتصال ]  [ واتساب ]
```
- **حالة فارغة:** «خلّصت متابعات اليوم 🎉»

---

## ١٠. تبويب «العملاء»

القائمة الكاملة.

- **بحث** ثابت أعلى: «ابحث باسم أو جوال»
- **شرائح فلترة** أفقية قابلة للتمرير:
  `الكل · لم يتم التواصل · جديد · مهتم · زيارة · في الانتظار · حسبة البنك · تفاوض · محجوز · مقفول`
- الشريحة النشطة ذهبية مملوءة، الباقية بحدود
- **الترتيب** (أيقونة يسار البحث): نشاط (افتراضي) · الأحدث · الأقدم · الاسم
- تمرير لانهائي (٢٠ في الدفعة)، لا ترقيم صفحات
- **حالة فارغة للبحث:** «ما لقينا أحد بهذا الاسم أو الرقم»

> «مهتم» شريحة مظلّة تشمل: `INTERESTED` + `VIEWING` + `NEGOTIATION` + `FOLLOW_UP_LATER`

## ١١. ملف العميل

### الترويسة (ثابتة عند التمرير)
```
‹ رجوع                                    ⋯
فهد العتيبي
٠٥٠١٢٣٤٥٦٧ · تيك توك              [بادج المرحلة]
```
قائمة `⋯`: تعديل الاسم/الجوال · نقل لموظف (للمدير فقط) · أرشفة

### شريط الإجراءات (ثابت أسفل الترويسة)
```
[ اتصال ]   [ واتساب ]   [ تسجيل متابعة ]
```
«تسجيل متابعة» ذهبي مملوء.

### البيانات الأساسية
بطاقة مضغوطة: المصدر · تاريخ الإضافة · الموظف المسؤول · هدف الشراء · المتابعة القادمة

### الخط الزمني للمتابعات
الأحدث أولًا. كل عنصر:
```
●  مهتم — موعد زيارة                   قبل يومين
│  «العميل يبي دور أرضي، ميزانيته ٨٠٠ ألف»
│  عبير الحربي
```
نقطة ملوّنة حسب نوع النتيجة، وخط رأسي يربط العناصر.

**ملاحظة صلاحيات:** سجل التحويلات بين الموظفين مخفي عن الموظف، ظاهر للمالك.

## ١٢. ورقة تسجيل المتابعة (أهم عنصر في التطبيق)

ورقة سفلية (bottom sheet) تنزلق من تحت. مقبض رمادي أعلاها. الضغط خارجها يغلقها.

### ١٢-أ. الفتح التلقائي بعد المكالمة

عند الضغط على «اتصال»: يفتح متصل الجوال. **لما يرجع الموظف للتطبيق، الورقة تفتح تلقائيًا** بسؤال:

```
وش صار مع فهد؟
```

> قيد تقني: النظامان لا يسمحان بمعرفة مدة المكالمة أو إن كان العميل ردّ. الاكتشاف يتم عبر رجوع التطبيق للمقدمة (Capacitor App resume). لذلك لا تعرض «انتهت المكالمة · ١:٢٤» — اعرض السؤال مباشرة.

### ١٢-ب. الحالة الأولى: أول تواصل

إذا `firstContactStage === null` — تُعرض هذي الشاشة **فقط**، وتتجاوز أزرار المرحلة:

**أربعة أزرار كبيرة:**

| الزر | الخطوة الثانية |
|---|---|
| **مهتم** | اختياري: موعد متابعة (بدون إجبار) |
| **لا يرد** | لا شيء |
| **طلب التواصل في وقت آخر** | تاريخ ووقت إلزامي |
| **غير مهتم** | شرائح الأسباب + «نحاول لاحقًا؟» |

### ١٢-ج. الحالة الثانية: أزرار حسب المرحلة

تُعرض الأزرار المطابقة لمرحلة العميل الحالية:

| المرحلة | الأزرار |
|---|---|
| `NEW` · `ATTEMPTED` | مهتم · لم يرد · موعد لاحق · غير مهتم |
| `INTERESTED` | زيارة · موعد لاحق · تفاوض · حسبة البنك · في الانتظار · غير مهتم |
| `FOLLOW_UP_LATER` | مهتم · زيارة · حسبة البنك · في الانتظار · غير مهتم |
| `VISIT_SCHEDULED` | زيارة · ما حضر — إعادة جدولة · ما حضر — ما يبي · حسبة البنك · في الانتظار · غير مهتم |
| `VIEWING` | تفاوض · حسبة البنك · في الانتظار · غير مهتم |
| `NEGOTIATION` | تم الحجز · حسبة البنك · في الانتظار · غير مهتم |
| `RESERVED` · `CLOSED_WON` · `CLOSED_LOST` | لا شيء → «ما فيه إجراءات متابعة لهذه المرحلة» |

**تخطيط الأزرار:** شرائح مرنة تلتف على سطرين، ارتفاع ٤٤ نقطة، النشط ذهبي مملوء.

### ١٢-د. الحقول المشتركة

بعد اختيار النتيجة:

1. **ملاحظة** — حقل نص مع **أيقونة ميكروفون ذهبية** للإملاء الصوتي (أهم من الكتابة — الموظف غالبًا في السيارة)
2. **المتابعة الجاية** — صف قابل للضغط يفتح منتقي تاريخ. اختصارات سريعة: `بكرة · بعد يومين · بعد أسبوع · تاريخ محدد`
3. زر **«حفظ»** ذهبي بعرض كامل

### ١٢-هـ. حقول شرطية

| النتيجة | الحقل الإضافي |
|---|---|
| **زيارة** | المكان: مشروع / مكتب · الوحدة (اختياري) · التاريخ إلزامي (إلا إن جاء من `VISIT_SCHEDULED`) |
| **في الانتظار** | «ينتظر إيش؟» — نص إلزامي + موعد الرجوع |
| **حسبة البنك** | البنك (اختياري) + موعد المتابعة |
| **طلب التواصل في وقت آخر** | تاريخ ووقت إلزامي |
| **غير مهتم** | شرائح الأسباب (الموقع / السعر / المساحة / نهائي) + «نحاول لاحقًا؟» نعم+تاريخ أو لا |
| **تم الحجز** | لا يُرسل متابعة — يفتح شاشة الحجز |

**بعد الحفظ:** الورقة تنغلق مع اهتزاز خفيف، وشريط أخضر قصير «انحفظت ✓»، والبطاقة تختفي من قائمة اليوم.

## ١٣. ورقة قوالب واتساب

ورقة سفلية عند الضغط على «واتساب».

```
رسالة لفهد
تنرسل من واتساب جوالك
```

ثلاثة قوالب، كل واحد بطاقة قابلة للضغط تعرض النص كامل:

| القالب | النص |
|---|---|
| **ترحيب** | هلا فهد، معك عبير من مشاريع السلطان. وصلني طلبك وأحب أخدمك — أبغى أفهم وش تدور بالضبط؟ |
| **تذكير موعد** | هلا فهد، تذكير بموعد المعاينة بكرة الساعة ١١ في مشروع ٨٠. يناسبك؟ |
| **متابعة** | هلا فهد، حبيت أطمن عليك — وصلتك التفاصيل؟ أي استفسار أنا حاضرة. |

أسفلها: زر «رسالة جديدة» بحدود فقط (يفتح واتساب فاضي).

**السلوك:** يفتح واتساب الموظف نفسه بالرسالة جاهزة. لا نرسل نيابة عنه، ولا نحتاج أي API. اسم العميل واسم الموظف يُعبّآن تلقائيًا.

**تسجيل تلقائي:** عند الرجوع للتطبيق، تفتح ورقة تسجيل مختصرة: «أرسلت لفهد؟» بزرين — نعم / ما أرسلت.

## ١٤. تبويب «المزيد»

### أعلى الشاشة
```
[دائرة]  عبير الحربي
         مستشارة مبيعات
```

### بطاقتا إحصاء
`عملائي: ١٢٤` · `حجوزات الشهر: ٤`

### قائمة الروابط

| العنصر | ملاحظة |
|---|---|
| **الحجوزات** | استخدام قليل — هنا وليس في الشريط السفلي |
| **العملاء المؤرشفون** | — |
| **الإشعارات** | تفعيل/تعطيل |
| **البصمة / Face ID** | مفتاح تبديل |
| **تغيير الرمز السري** | — |
| **تسجيل الخروج** | نص أحمر |

**للمالك فقط، تُضاف:**
- التوزيع التلقائي (مفتاح + إعدادات)
- العملاء المكرّرون (بشارة عدد)
- سجل العمليات
- إدارة الجلسات

### أسفل الشاشة
```
رقم فال ١٢٠٠٠٢١٠٢٩
الإصدار ١٫٠٫٠
```

## ١٥. شاشة الحجوزات (استخدام منخفض)

من «المزيد» فقط. عرض للقراءة — الإنشاء والتعديل في الويب.

بطاقة الحجز:
```
خالد الشمري                        [محجوز]
مشروع ٧٦ ظهرة لبن · شقة ٤
────────────────────────────
المحصّل            ٥٠٬٠٠٠ ريال سعودي
المتبقي           ٤٥٠٬٠٠٠ ريال سعودي
```

**قيد صلاحيات:** البيانات المالية مخفية عن غير المالك والمدير وصاحب الحجز.

## ١٧. الحالات والسلوك

**التحميل:** هياكل عظمية (skeletons) بلون `#141416` نابضة — لا دوّارات.

**بدون إنترنت:** شريط علوي `#412402` بنص «ما فيه اتصال — البيانات آخر تحديث ١٠:٣٠». التطبيق **يعرض آخر بيانات محمّلة للقراءة فقط**، ويعطّل أزرار الحفظ. لا تعديل بدون اتصال.

**الأخطاء:** رسالة بلهجة واضحة + زر «حاول مرة ثانية». لا رموز خطأ تقنية.

**الحالات الفارغة:** أيقونة خافتة + جملة قصيرة إيجابية.
