لوحة الأسبوع — قسم داخل الرئيسية

سباق الأشرطة (٣) كقسم بالرئيسية مباشرة، بلا صفحة منفصلة. + فلتر: هذا الأسبوع / السابق / مخصّص (جرّب «مخصّص» يطلع حقلي التاريخ). ليل + نهار.
