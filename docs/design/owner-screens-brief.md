# بريف الشاشات الداخلية — قسم المالك

تكملة لبريف التطبيق الأساسي. يغطي الشاشات الثماني اللي تفتح من بطاقات «المزيد — مالك».

**قاعدة حاكمة:** كل شاشة هنا **للمالك والمدير فقط**، والصلاحية مفروضة على الخادم لا الواجهة. أي محاولة وصول من موظف تُرجع ٤٠٣.

**نفس الهوية:** أوبسيديان `#0A0A0B` · بطاقات `#141416` · ذهبي `#CBA45E` · RTL كامل · أرقام عربية · مبالغ بالريال السعودي كاملة.

**نمط ثابت لكل الشاشات:** ترويسة فيها `‹ رجوع` يمين + عنوان الشاشة، ثم المحتوى.

---

## ١. المشاريع والوحدات

### ١-أ. قائمة المشاريع

ترويسة: «المشاريع والوحدات» + سطر ثانوي `٤ مشاريع · ٥٩٠ وحدة`

**بطاقة المشروع:**
```
┌────────────────────────────────
│ مشروع السلطان ٨٠            [نشط]
│ ظهرة لبن · الرياض
│
│ ▓▓▓▓▓▓▓░░░░░░░░  ٤٢٪ مباع
│
│ متاح ٨٦   محجوز ١٢   مباع ٧٢
└────────────────────────────────
```
- شريط التقدّم ذهبي على خلفية `#26262A`
- الأرقام الثلاثة بألوانها: متاح رمادي · محجوز `#FAC775` · مباع `#C0DD97`
- الضغط يفتح تفاصيل المشروع

**فلترة أعلى:** `الكل · نشط · مكتمل`

### ١-ب. تفاصيل المشروع

ترويسة بصورة المشروع (إن وُجدت) بتدرّج أسود لأسفل، والاسم فوقها.

**شريط إحصاء أفقي:** إجمالي الوحدات · المتاح · المحجوز · المباع · نسبة الإشغال

**شرائح فلترة:** `الكل · متاح · محجوز · مباع · مسلّم`
**فلتر النوع:** `شقق · أدوار · بنتهاوس`

**شبكة الوحدات — عمودان:**
```
┌──────────────┐
│ شقة ١٢       │
│ الدور ٣      │
│ ١٤٠ م²       │
│ ٧٥٠٬٠٠٠ ريال  │
│ [متاح]       │
└──────────────┘
```
- حدّ الوحدة ملوّن حسب الحالة
- الوحدة المباعة: خلفية أغمق `#0F0F11` + شارة صغيرة باسم المشتري

### ١-ج. تفاصيل الوحدة (ورقة سفلية)

```
شقة ١٢ — مشروع ٨٠
─────────────────────
النوع            شقة
الدور            ٣
المساحة          ١٤٠ م²
الغرف            ٣ + صالة
السعر            ٧٥٠٬٠٠٠ ريال سعودي
الحالة           [محجوز]
─────────────────────
العميل           خالد الشمري
الموظف           عبير الحربي
المحصّل           ٥٠٬٠٠٠ ريال سعودي
المتبقي          ٧٠٠٬٠٠٠ ريال سعودي
```
زر أسفل: «فتح ملف الحجز ›»

**الوحدة المتاحة:** يظهر بدلها زر «ما فيه حجز على هذي الوحدة».

**حالة فارغة:** «ما فيه وحدات بهذا الفلتر».

## ٢. خط المبيعات

بديل الكانبان على الجوال — **قائمة عمودية مجمّعة بالمرحلة**، لا سحب وإفلات.

ترويسة: «خط المبيعات» + `٩ قيد البيع · ٦٠ مباع`

### ٢-أ. القمع أعلى الشاشة

أشرطة أفقية متدرجة العرض:
```
مهتم        ▓▓▓▓▓▓▓▓▓▓  ٣٤
زيارة       ▓▓▓▓▓▓▓░░░  ٢١
تفاوض       ▓▓▓▓░░░░░░  ١٢
محجوز       ▓▓░░░░░░░░   ٩
مباع        ▓▓▓▓▓▓░░░░  ٦٠
```
كل شريط بلون مرحلته من `stage-colors`. الضغط يمرّر للقسم المقابل.

### ٢-ب. الأقسام

عنوان قسم لكل مرحلة (لاصق عند التمرير) + عدد، وتحته بطاقات مضغوطة:
```
خالد الشمري                  ٧٥٠٬٠٠٠ ريال
مشروع ٨٠ · شقة ١٢ · عبير الحربي
في هذي المرحلة منذ ٤ أيام
```
- **تنبيه ركود:** العميل اللي تجاوز ١٤ يوم في نفس المرحلة يظهر بشريط `#C98A16` ونص «راكد ١٦ يوم»

**فلتر الموظف** أعلى: شرائح بأسماء الفريق + «الكل».

**فلتر الفترة:** `اليوم · ٧ أيام · الشهر · الكل`

## ٣. الفريق

ترويسة: «الفريق» + `٦ موظفين`

### ٣-أ. بطاقة الموظف

```
┌────────────────────────────────
│ [ع]  عبير الحربي              ⋯
│      مستشارة مبيعات · متصلة الآن
│
│ ▓▓▓▓▓▓▓░░░  ٧٠٪ من الهدف
│
│ عملاء ١٢٤ · متابعات اليوم ٨ · حجوزات ٤
└────────────────────────────────
```
- **مؤشر التواجد:** نقطة خضراء «متصلة الآن» أو رمادية «آخر ظهور قبل ساعتين»
- **تنبيه:** الموظف اللي عنده متابعات متأخرة → شريط التقدّم أحمر + شارة «٣ متأخرة»
- قائمة `⋯`: عرض عملائه · إنهاء جلساته · تعطيل الحساب

**ترتيب:** الأعلى أداءً أولًا (افتراضي) · أو بالاسم · أو بالمتأخرات

### ٣-ب. صفحة الموظف

**بطاقات مؤشرات ٢×٣:** إجمالي عملائه · لم يتم التواصل · متابعات اليوم · متأخرة · زيارات الشهر · حجوزات الشهر

**قمع مصغّر** لعملائه هو فقط.

**نشاطه اليوم:** خط زمني بآخر المتابعات اللي سجّلها.

**الأجهزة النشطة:** قائمة الجلسات مع زر «إنهاء» لكل جلسة، وزر «إنهاء كل الجلسات» أحمر.

## ٤. التحليلات — «اسأل بياناتك»

واجهة محادثة، لا لوحات معقّدة.

### ٤-أ. أعلى الشاشة — أربع بطاقات سريعة (٢×٢)
`عملاء الشهر` · `معدل التحويل` · `متوسط أيام الإغلاق` · `إجمالي المحصّل`

كل بطاقة: الرقم كبير + سهم اتجاه أخضر/أحمر ونسبة التغيّر عن الفترة السابقة.

### ٤-ب. أسئلة جاهزة

شرائح قابلة للضغط:
```
كم عميل جانا من تيك توك هذا الشهر؟
مين أفضل موظف من ناحية التحويل؟
كم متوسط الوقت من أول تواصل للحجز؟
أي مشروع أسرع بيعًا؟
وش أكثر سبب لعدم الاهتمام؟
```

### ٤-ج. المحادثة

- حقل إدخال ثابت أسفل + **أيقونة ميكروفون** للسؤال الصوتي
- رد المساعد يظهر كبطاقة: نص + رسم بياني بسيط عند اللزوم (أشرطة أفقية فقط — لا رسوم دائرية ولا خطوط معقّدة على الجوال)
- تحت كل رد: «شوف التفاصيل في الويب ›»

**قيد مهم:** المساعد يقرأ فقط. لا ينفّذ أي تعديل على البيانات.

## ٥. مراحل العملاء

شاشة عرض وتحرير لمنظومة المراحل. هذي **مصدر الحقيقة للألوان** في كل النظام.

ترويسة: «مراحل العملاء» + «كائنات الشركة»

### ٥-أ. قائمة المراحل

صف لكل مرحلة:
```
●  جديد                        ١٢ عميل    ›
●  لم يتم التواصل              ٢٣ عميل    ›
●  مهتم                        ٣٤ عميل    ›
●  زيارة مجدولة                 ٨ عملاء    ›
●  زار المشروع                  ٦ عملاء    ›
●  تفاوض                       ١٢ عميل    ›
●  في الانتظار                 ٧٠ عميل    ›
●  حسبة البنك                  ١٤ عميل    ›
●  محجوز                        ٩ عملاء    ›
●  مباع                        ٦٠ عميل    ›
●  غير مهتم                   ١٦٧ عميل    ›
```
النقطة الملوّنة بلون المرحلة الفعلي. الضغط يفتح تفاصيلها.

### ٥-ب. تفاصيل المرحلة (ورقة سفلية)

```
مهتم
─────────────────────
اللون          [مربع ملوّن] #639922
عدد العملاء     ٣٤
متوسط البقاء    ٦ أيام
يشملها فلتر     مهتم (مظلّة)
─────────────────────
الإجراءات المتاحة من هذي المرحلة:
زيارة · موعد لاحق · تفاوض · حسبة البنك ·
في الانتظار · غير مهتم
```
زر: «شوف عملاء هذي المرحلة ›»

### ٥-ج. أسباب عدم الاهتمام

قسم منفصل أسفل الشاشة:
```
الموقع        ٤٢
السعر         ٦٨
المساحة       ٢١
نهائي         ٣٦
```
أشرطة أفقية بالنسب — يعطي المالك صورة فورية عن أكبر سبب فقدان.

## ٦. التوزيع التلقائي

أهم شاشة تحكّم عند المالك. الشارة الحمراء تعرض عدد العملاء غير الموزّعين.

### ٦-أ. أعلى الشاشة — حالة النظام

بطاقة كبيرة:
```
التوزيع التلقائي              [ ●━━ ]  شغّال
آخر توزيعة: قبل ٢٥ دقيقة · ٨ عملاء
```
المفتاح ذهبي عند التشغيل، رمادي عند الإيقاف.

**إذا فيه غير موزّعين:** بطاقة حمراء تحته
```
٢٣ عميل غير موزّع
[ وزّعهم الآن ]
```

### ٦-ب. إعدادات التوزيع

| الإعداد | الشكل |
|---|---|
| **طريقة التوزيع** | ثلاث شرائح: بالتناوب · الأقل حِملًا · الأكثر نشاطًا |
| **حجم الدفعة** | منزلق (stepper) بأزرار − / + |
| **ساعات العمل** | من ٩:٠٠ إلى ٦:٠٠ — صفّان قابلان للضغط |
| **الحد اليومي للموظف** | stepper |
| **أيام العمل** | شرائح أيام الأسبوع، النشط ذهبي |

### ٦-ج. سحب صامتي التواصل

قسم منفصل بعنوان واضح:
```
سحب العملاء اللي ما تم التواصل معهم    [ ●━━ ]
```
تحته السلّم الثلاثي:
```
المستوى الأول    بعد ٣ أيام
المستوى الثاني   بعد يومين
المستوى الثالث   فوري
```
كل مستوى بـ stepper مستقل.

**إعدادات الحماية** (اعرضها كقائمة مقروءة، لا مفاتيح — هذي ثوابت أمان):
- حصانة العميل بعد ٥ متابعات
- حد أدنى ٦٠ دقيقة قبل أي سحب
- تحذير مسبق للموظف قبل السحب
- العملاء المتعذّر الوصول إليهم محميون

### ٦-د. سجل التوزيعات

آخر ١٠ عمليات:
```
قبل ٢٥ دقيقة    ٨ عملاء → ٣ موظفين      [بالتناوب]
قبل ساعتين      ١٢ عميل → ٤ موظفين      [الأقل حِملًا]
اليوم ٩:٠٠      ٦ عملاء مسحوبين → أُعيد توزيعهم
```

## ٧. الإعدادات

### ٧-أ. بيانات الشركة
```
اسم الشركة       مشاريع السلطان
الشعار           [معاينة مصغّرة]  تغيير ›
رقم فال REGA     ١٢٠٠٠٢١٠٢٩
رقم التواصل      ٠٥٠١١٥٥٤٤٧
```

### ٧-ب. الموظفون
صف لكل موظف: الاسم · الدور · الحالة (نشط/معطّل) · `›`
زر أسفل القائمة: «+ إضافة موظف»

**تفاصيل الموظف:** تغيير الدور · إعادة تعيين الرمز · تعطيل الحساب · إنهاء الجلسات

### ٧-ج. العملاء المكرّرون
صف بشارة عدد. يفتح شاشة بقسمين:
- **نشطون** — مكرّرون في مراحل عمل
- **محجوزون/مباعون** — مكرّرون أتمّوا شراء

كل بطاقة تعرض النسختين جنبًا لجنب مع الفروقات، وأزرار: `دمج` · `احتفظ بالاثنين` · `احذف المكرّر`

### ٧-د. إدارة الجلسات
كل الأجهزة النشطة عبر الفريق، مع زر «إنهاء كل الجلسات» أحمر أسفل الشاشة.

### ٧-هـ. الإشعارات
مفاتيح: ليد جديد · حجز جديد · تجاوز خصم · متابعات متأخرة

## ٨. سجل التدقيق

ترويسة: «سجل التدقيق» + «مين غيّر وش»

### ٨-أ. الفلاتر

- **الفترة:** `اليوم · أمس · ٧ أيام · ٣٠ يوم`
- **الموظف:** شرائح بالأسماء + «الكل»
- **نوع العملية:** `الكل · تعديل عميل · متابعة · حجز · نقل · حذف · دخول`

### ٨-ب. القائمة

مجمّعة بعناوين تاريخية (اليوم / أمس / الأحد ٢٠ يوليو).

**عنصر السجل:**
```
●  عبير الحربي  غيّرت مرحلة  فهد العتيبي
   من «مهتم» إلى «زيارة مجدولة»
   ١١:٢٤ ص
```
- اسم الموظف واسم العميل **روابط** — الضغط يفتح الملف المقابل
- نقطة ملوّنة حسب نوع العملية
- **التجميع الذكي:** العمليات المتشابهة المتتالية تُدمج — «عبير سجّلت ٦ متابعات · ١١:٢٤ – ١١:٥٢ ›» والضغط يفكّها

### ٨-ج. درج التفاصيل

ورقة سفلية عند الضغط على أي عنصر:
```
تعديل مرحلة
─────────────────────
العميل        فهد العتيبي  ›
الموظف        عبير الحربي  ›
الحقل         المرحلة
قبل           مهتم
بعد           زيارة مجدولة
الوقت         ٢٠ يوليو ٢٠٢٦ · ١١:٢٤ ص
الجهاز        iPhone · الرياض
```

**التوقيت:** آسيا/الرياض بالتقويم الميلادي في كل مكان.

### ٨-د. عدّادات الموظفين
شريط أعلى القائمة: `عبير ٤٢ · محمد ٣١ · أسماء ٢٨ …` — عدد العمليات في الفترة المحددة.

## ٩. ملاحظات تنفيذية للتصميم

**العمق الأقصى ثلاث طبقات:** بطاقة «المزيد» ← الشاشة ← ورقة تفاصيل. لا تعمّق أكثر.

**الأوراق السفلية** تُستخدم للتفاصيل والتحرير السريع. الشاشات الكاملة للقوائم.

**كل قائمة تحتاج:** حالة تحميل (هياكل عظمية) · حالة فارغة (أيقونة + جملة) · حالة خطأ (رسالة + إعادة محاولة).

**ما لا يدخل حتى عند المالك:** الاستيراد · إنشاء المشاريع والوحدات · تعديل ألوان المراحل · التقارير القابلة للتصدير. تبقى في الويب مع رابط «افتح في الويب ›».

4. خط المبيعات
5. الفريق — القائمة
6. الفريق — صفحة موظف
7. التحليلات — اسأل بياناتك
8. مراحل العملاء
9. التوزيع التلقائي
10. الإعدادات — الرئيسية
11. العملاء المكرّرون
12. سجل التدقيق + درج التفاصيل
